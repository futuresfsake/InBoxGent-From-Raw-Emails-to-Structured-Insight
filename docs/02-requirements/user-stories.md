# User Stories

Personas:
- **Analyst (the author)**: builds and runs the pipeline.
- **Reviewer**: a recruiter or hiring manager evaluating the portfolio.
- **Researcher**: someone who wants to reuse the cleaning or evaluation code.

| ID | As a... | I want... | So that... | Reqs |
|---|---|---|---|---|
| US-01 | Analyst | to load and sample the Enron corpus reproducibly | every run starts from the same data | FR-01, NFR-01 |
| US-02 | Analyst | headers parsed into structured columns | I can analyze senders, recipients and time | FR-02 |
| US-03 | Analyst | signatures, quotes and forwards stripped | the body contains only new content | FR-03, FR-04 |
| US-04 | Analyst | duplicates removed | counts and models are not skewed | FR-05 |
| US-05 | Analyst | a log of what each cleaning step removed | I can justify every cleaning decision | FR-06 |
| US-06 | Analyst | entities and values extracted from the body | emails become queryable records | FR-07 |
| US-07 | Analyst | to swap extraction backends | I can compare rules, NLP and LLM fairly | FR-08 |
| US-08 | Analyst | a hand-labeled gold set | accuracy is measured, not assumed | FR-09 |
| US-09 | Analyst | precision, recall and F1 per field | I can see where each approach wins | FR-10 |
| US-10 | Analyst | cost and latency per backend | I can discuss trade-offs honestly | FR-11 |
| US-11 | Analyst | exploratory charts of the cleaned data | I can discover patterns before modeling | FR-12 |
| US-12 | Analyst | an email classifier with a baseline | I can show modeling skill with proper evaluation | FR-13 |
| US-13 | Analyst | automatically discovered topics | I can summarize what the corpus is about | FR-14 |
| US-14 | Reviewer | a short findings summary in the README | I can judge the project in five minutes | NFR-07 |
| US-15 | Reviewer | an explorable dashboard | I can see results without running code | FR-15 |
| US-16 | Researcher | cleanly separated, tested modules | I can reuse the cleaning and evaluation code | NFR-03, NFR-04 |

## Acceptance criteria (examples)
- **US-03:** On a 50-email manual spot check, at least 90% of bodies contain no signature or quoted reply text.
- **US-09:** A results table exists with one row per field per backend, generated by a script, not by hand.
- **US-12:** Reported metrics come from a held-out test set; the baseline and the improved model are shown side by side.
