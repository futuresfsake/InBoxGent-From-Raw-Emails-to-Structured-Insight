# Milestone Reference

Detailed task breakdown and exit criteria per milestone.

## M0 Foundation
- Create folder skeleton and `.gitignore` (ignore `data/raw`, `data/interim`, `data/outputs`)
- `requirements.txt`, virtual environment, `config.py`
- ruff and pre-commit setup
- **Exit:** a fresh clone can install dependencies and import `src`.

## M1 Ingest & Parse
- Download Enron corpus to `data/raw/`
- `ingest.py`: seeded sampling to a configurable size
- `parse.py`: headers to columns, UTC dates, normalized addresses
- **Exit:** `emails_parsed.parquet` exists; null-rate report for each column.

## M2 Cleaning
- Implement cleaning steps in the order defined in the LLD
- Exact and near-duplicate detection
- Cleaning log with per-step counts
- Unit tests on tricky samples (forwards, nested quotes, signatures)
- **Exit:** manual spot check of 50 emails meets the 90% acceptance threshold.

## M3 EDA
- Volume over time, top senders, sender-recipient network, length distribution, response-time estimate
- **Exit:** notebook with at least five charts and written takeaways.

## M4 Gold Set
- Select about 200 emails stratified across senders and folders
- Define annotation guidelines (what counts as person, org, date, amount, action item)
- Label, then double-check a 20% subset for consistency
- **Exit:** `data/labeled/gold.csv` committed with guidelines document.

## M5 Extraction & Evaluation
- Implement `rules`, `spacy`, `llm` backends behind the shared interface
- Run on the gold set, cache LLM output
- Compute precision, recall, F1 per field; record cost and latency
- Error analysis: categorize failures per backend
- **Exit:** metrics table generated by script plus written comparison.

## M6 Classification
- Define labels and label a training sample
- Baselines: majority class, TF-IDF + logistic regression
- Embedding variant, cross-validation, held-out test
- **Exit:** metrics with confusion matrix and discussion of errors.

## M7 Topics
- Embeddings, UMAP, clustering, topic term summaries
- **Exit:** topic table plus 2-D map, with human-readable topic names.

## M8 Polish & Publish
- Findings report in `reports/findings.md`
- README summary with top three results and figures
- Optional Streamlit dashboard
- **Exit:** a reviewer can understand the project in five minutes from the README.
