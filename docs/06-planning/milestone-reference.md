# Milestone Reference

Detailed scope, deliverables, exit criteria and key analyses per milestone.

## M0 Foundation and framing
**Tasks**
- Repo skeleton, `.gitignore` (raw, interim, features, outputs, mlruns), `pyproject.toml`, lock file
- Typed configuration, logging, CLI entry point, Makefile
- pre-commit: ruff, secret scan, large-file and data-path blockers, nbstripout
- GitHub Actions: lint, tests, fixture pipeline
- Synthetic fixture dataset (about 30 fake emails covering quotes, forwards, signatures, duplicates, threads)
- Lock problem framing, hypotheses and evaluation methodology

**Exit:** fresh clone installs and runs `make test` and the fixture pipeline green in CI.

## M1 Acquisition and data understanding
**Tasks**
- Download corpus; compute manifest
- Exact-duplicate hashing on the full corpus
- Seeded stratified sampler with inclusion probabilities
- Header parser, failure accounting
- First profiling pass; fill datasheet items marked verify

**Exit:** `emails_parsed` passes gates G1-G2; datasheet claims verified or corrected.

## M2 Cleaning, dedup, threads, quality gates
**Tasks**
- Implement ordered cleaning steps with lineage
- Boilerplate mining and review
- Near-duplicate clustering; choose threshold on a labeled pair sample (precision/recall)
- Thread reconstruction with confidence; audit 100 messages
- PII detection and redaction utilities
- Freeze `clean_v1`

**Exit:** gates G3-G5 pass; cleaning audit (100 emails) at least 90% clean, failures categorized; thread accuracy estimated with CI.

## M3 EDA and hypothesis refinement
**Tasks**
- Volume, custodian, length, recipient and missingness analysis
- Mass-mail and automated-mail share
- Document generated hypotheses separately from pre-registered ones
- Decide temporal split boundaries and T2 exclusion thresholds

**Exit:** EDA notebook with at least eight figures and written takeaways; split boundaries committed.

## M4 Annotation
**Tasks**
- Write guidelines; pilot on 20 emails; revise
- Select stratified gold sample plus hard-case set; assign dev/test by seeded hash
- Annotate; double-annotate at least 25%; compute agreement; adjudicate
- Commit test-id hash; label T1 sample (about 400 emails)

**Exit:** agreement targets met or guidelines revised; `data/labeled/` committed with hashes; test lock recorded.

## M5 Extraction benchmark
**Tasks**
- Common interface; rules, spaCy, LLM-small, LLM-large backends
- Prompt development on dev only; prompt version freeze
- Evaluator: strict, lenient, normalized matching; cluster bootstrap; paired tests; Holm correction
- Cost, latency, throughput measurement
- Error taxonomy and qualitative review
- Cost-quality Pareto plot

**Exit:** H1 and H2 resolved (supported, not supported, inconclusive) with CIs; reproducible metrics table generated by script.

## M6 Predictive modeling
**Tasks**
- Build T1 and T2 labels with exclusions and censoring handling
- Feature groups F1-F3; leakage tests
- Baselines and stronger models; bounded hyperparameter search
- Temporal, rolling-origin and random-grouped comparisons
- Calibration; ablations; SHAP and permutation importance; slice analysis
- Experiment tracking throughout

**Exit:** H3 (T1 part) and H4 resolved; model cards drafted; leakage tests green.

## M7 Topics, network and temporal analysis
**Tasks**
- Topic models on raw versus cleaned text; coherence and stability
- Network construction, centrality, Leiden communities, null-model comparison
- Change-point detection with event list from `config/events.yaml`; permutation baseline

**Exit:** H3 (topic part) and H5 resolved; sensitivity analyses recorded; exploratory label applied where appropriate.

## M8 Synthesis and release
**Tasks**
- Findings report: question, method, results, what did not work, limitations
- Model card, datasheet, ethics checklist
- README summary with three headline results and figures
- Reproducibility checklist; fresh-clone test; release tag

**Exit:** a reviewer can reproduce key tables and read the summary in five minutes.

## Stretch
- **Hybrid extractor:** confidence routing; cost-quality curve
- **Anomaly detection:** Isolation Forest on sender-week features
- **Active learning:** simulated labeling efficiency study
- **Dashboard:** Streamlit over precomputed results only
