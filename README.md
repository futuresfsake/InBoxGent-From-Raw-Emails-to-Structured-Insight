# InBoxGent: From Raw Emails to Structured Insight

A data science project that turns messy, unstructured email into clean structured data, evaluates how well different extraction approaches work, and analyzes the result to reveal communication patterns.

> Status: documentation phase. Implementation has not started. See [docs/](docs/) for the full plan.
